# Desafio-DIO
Projeto desenvolvido em Excel com o objetivo de criar um simulador de investimentos em Fundos Imobiliários (FIIs). A ferramenta permite analisar a divisão dos aportes de acordo com o perfil do investidor e projetar a evolução do patrimônio e dos dividendos ao longo do tempo, utilizando funções como VF e PROCV.
